# GoldIn — Jual Emas Segala Kondisi

Website landing page untuk jual beli emas segala kondisi. Dibangun dengan HTML, CSS, dan JavaScript vanilla.

## 🔗 Live Demo
[https://gold-in.vercel.app](https://gold-in.vercel.app)

## 📁 Struktur File
```
goldin/
├── index.html      # Struktur halaman
├── style.css       # Styling & animasi
├── sitemap.xml     # Peta situs untuk Google
└── README.md       # Dokumentasi
```

## ✨ Fitur
- Hero section dengan animasi koin emas
- Section kondisi emas yang diterima
- Proses transaksi 3 langkah
- Keunggulan layanan
- Kontak via WhatsApp & Instagram
- Fully responsive (mobile & desktop)
- Animasi scroll reveal
- SEO optimized

## 🎨 Design
- **Font:** Cormorant Garamond + DM Sans
- **Tema:** Dark blue-purple gradient
- **Style:** Glassmorphism + subtle animations
